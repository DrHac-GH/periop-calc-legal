周術期・集中治療計算ツール／最終更新日: 2026-09-14
English

本アプリ「周術期・集中治療計算ツール」（以下「本アプリ」）は、周術期・集中治療で使う式・尺度・換算の計算を行うアプリです。本ポリシーは、本アプリが扱う情報とその使い道を説明します。

1. 提供者

アプリ名: 周術期・集中治療計算ツール（英語名 Perioperative & ICU Calculator）
提供者: Dr. Hac
連絡先: drhac.jp@gmail.com

2. 扱う情報

本アプリは、氏名・メールアドレス・電話番号などの登録を求めません。アカウントもありません。扱う情報は次のとおりです。

種類内容目的保存先
計算に入れた値体重・検査値・投与量など、計算のために入れた値計算結果の表示保存しません（画面を閉じると消えます）。どこにも送信しません
お気に入り・最近使った計算・言語の設定選んだ計算の名前（ID）と表示の言語一覧の表示お使いの端末の中だけ

本アプリは、患者さんの情報・正確な位置情報・連絡先・写真・健康に関するデータを取得しません。利用状況の分析（アナリティクス）のツールも使っていません。

本アプリに患者さんの氏名など個人が分かる情報を入れないでください。「問題を報告」の詳しい内容の欄にも、患者さんの情報や計算に入れた値を書かないでください。

新しい版のお知らせのため、アプリは公開中の版の番号を Firebase から読み取ります（あなたの情報は送りません）。

広告について

本アプリは Google AdMob によるバナー広告を表示します。iOS では、はじめて使うときに「トラッキングの許可」（App Tracking Transparency）を確認します。許可しない場合は、広告識別子を使わない、あなた向けに合わせない広告を表示します。どちらを選んでも、計算の機能は変わりません。

  • Google による広告のデータの扱い: https://policies.google.com/technologies/partner-sites
  • トラッキングの許可は、iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」から、Android の広告 ID は端末の「設定」→「プライバシー」→「広告」からいつでも変えられます。

ウェブ版について

ウェブ版（drhac-gh.github.io/periop-calc）は、計算を端末のブラウザの中だけで行い、入力した値を送信しません。広告はありません。ページの配信は GitHub Pages（GitHub, Inc.）で行っており、アクセスの記録は GitHub が扱います。

3. 第三者への提供・委託

取得した情報を第三者へ販売することはありません。法令にもとづく開示の求めがあった場合を除き、上記の目的の範囲で次の事業者が情報を扱います。

  • Google LLC（Firebase Authentication・Cloud Firestore）：匿名認証の処理、問題の報告の保存、公開中の版の番号の配信
  • Google LLC（AdMob）：広告の配信のため、広告に関する情報を扱います

4. 情報の削除

お気に入り・最近使った計算・言語の設定は、本アプリを端末から削除するとすべて消えます。匿名利用者IDや送った問題の報告の削除を希望する場合は、上記の連絡先までご連絡ください。広告に関する情報の扱いは、上記の Google のページをご覧ください。
